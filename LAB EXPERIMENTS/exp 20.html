Oracle VirtualBox Installation

Custom Installation on Windows 10

Aim

To install Oracle VirtualBox on Windows 10 using custom installation and create virtual machines with different flavours of Linux or Windows operating systems.

Requirements

  • Windows 10 computer
  • Oracle VirtualBox software
  • Linux or Windows ISO file
  • Minimum 4 GB RAM (8 GB recommended)
  • At least 25 GB free disk space

Installation Procedure

  1. Download Oracle VirtualBox from its official website.
  2. Open the downloaded setup file.
  3. Click Next to start installation.
  4. Select Custom Installation.
  5. Choose the installation location.
  6. Select required features and click Next.
  7. Click Install to install VirtualBox.
  8. After installation, open Oracle VirtualBox.
  9. Click New to create a virtual machine.
  10. Enter the virtual machine name.
  11. Select the operating system type and version.
  12. Allocate RAM and create a virtual hard disk.
  13. Attach the downloaded ISO file.
  14. Click Start to install the operating system.
