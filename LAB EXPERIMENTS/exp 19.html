C Compiler Installation in Virtual Machine

1. Aim

To install a C compiler in a Virtual Machine using VirtualBox or VMware and execute simple C programs.

2. Requirements

  • Computer or Laptop
  • VirtualBox or VMware Workstation
  • Ubuntu Linux Operating System
  • GCC C Compiler
  • Internet Connection

3. Installation Procedure

  1. Open VirtualBox or VMware.
  2. Start the installed Ubuntu Virtual Machine.
  3. Open the Terminal.
  4. Update the system using the command:
sudo apt update

Install GCC compiler using:

sudo apt install gcc -y

Check the compiler installation:

gcc --version

4. Create a C Program

Open the terminal and type:

nano hello.c

Enter the following C program:

#include <stdio.h>

int main()
{
    printf("Hello World!");
    return 0;
}

Save the file by pressing CTRL + O, Enter, and CTRL + X.

5. Compile the C Program

gcc hello.c -o hello

6. Execute the Program

./hello

7. Output

Hello World!

8. Another Simple C Program

Add two numbers:

#include <stdio.h>

int main()
{
    int a = 10, b = 20, sum;

    sum = a + b;

    printf("Sum = %d", sum);

    return 0;
}

Compile and execute:

gcc sum.c -o sum
./sum

Output

Sum = 30

9. Result

Thus, GCC C compiler was successfully installed in the Ubuntu Virtual Machine and simple C programs were compiled and executed successfully.
