VirtualBox / VMware Installation

Aim

To install VirtualBox or VMware Workstation on a Windows 7 or Windows 8 computer and run different flavours of Linux or Windows operating systems using virtual machines.

Software Requirements

  • Windows 7 or Windows 8 operating system.
  • Oracle VirtualBox or VMware Workstation.
  • Linux or Windows ISO file.
  • Minimum 4 GB RAM (recommended).
  • Minimum 25 GB free hard disk space.

Installation Procedure

  1. Download VirtualBox or VMware Workstation.
  2. Open the downloaded installation file.
  3. Click the Next button.
  4. Accept the license agreement.
  5. Select the installation location.
  6. Choose the required installation features.
  7. Click Install to complete the installation.
  8. Open VirtualBox or VMware Workstation.
  9. Click New or Create a New Virtual Machine.
  10. Enter the virtual machine name.
  11. Select the Linux or Windows operating system.
  12. Allocate RAM and hard disk space.
  13. Attach the operating system ISO file.
  14. Click Start or Power On.
  15. Follow the instructions to install the guest OS.
